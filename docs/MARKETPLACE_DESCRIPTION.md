# TimeTracker Pro — Учёт рабочего времени для Битрикс24

## Описание

**TimeTracker Pro** — решение для детального учёта и анализа трудозатрат на базе Смарт-процессов Битрикс24. Приложение встраивается прямо в карточку задачи и предоставляет гибкую систему отчётности с иерархической группировкой данных.

---

## Ключевые возможности

### ⏱ Учёт времени прямо в задаче
Встроенный виджет во вкладке задачи позволяет мгновенно фиксировать рабочее время без переключения контекста. Поддерживается:
- Автоматический сбор иерархии задач (от корневой до подзадачи)
- Привязка к проекту и сотруднику
- Разделение записей (split) с сохранением всех связей
- Указание оплачиваемых и неоплачиваемых часов

### 📊 4 типа отчётов
| Отчёт | Группировка | Назначение |
|-------|-------------|------------|
| **По сотрудникам** | Сотрудник → Проект → Задача | Оценка загрузки команды |
| **По проектам** | Проект → Сотрудник → Задача | Анализ затрат на проект |
| **Ежедневная нагрузка** | Табель: Сотрудник × Дни | Контроль заполнения таймшетов |
| **По проектам/задачам** | Проект → Задача → Сотрудник → Метки | Детальная разбивка по задачам |

Все отчёты поддерживают **фильтрацию** по датам, сотрудникам и проектам, а также **экспорт в Excel**.

### ⚙️ Гибкая настройка
- Выбор любого Смарт-процесса в качестве источника данных
- Визуальный маппинг полей (без программирования)
- Настройка хранится в `app.option` — у каждого портала своя конфигурация

### 📤 Интеграция с Битрикс24
- Перенос учтённых часов в стандартные отчёты Битрикс24 (`task.elapseditem.add`)
- Экспорт для бухгалтерии (Excel)
- Расчёт стоимости для клиента (настраиваемая часовая ставка)

## Технические требования

- Битрикс24 облачная версия
- Тариф: Профессиональный и выше (для работы со Смарт-процессами)
- Поддерживаемые браузеры: Chrome, Firefox, Safari, Edge (последние версии)

---

## Как начать

1. Установите приложение из Маркетплейса
2. Перейдите в **Настройки → Маппинг**
3. Нажмите **«Создать Смарт-процесс»** и **«Создать все поля»** для автоматической настройки
4. Откройте любую задачу → вкладка **Учёт часов** → начните вносить время
5. Перейдите на главную страницу приложения для доступа к отчётам
