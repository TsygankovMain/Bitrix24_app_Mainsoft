# Mockup 04: Drawer карточки проекта

## Цель экрана
Показать, где редактируются проектные поля, которых нет штатно в проекте Bitrix24.

```text
| Доска проектов                                                                                                   |
+==================================================================================================================+
| ...                                                                                                              |
+==================================================================================================================+
                                               +------------------------------------------------------------------+
                                               | Проект: ACME внедрение                                           |
                                               | ID проекта: 157                                                  |
                                               |                                                                  |
                                               | Стадия:            [В работе                             v]      |
                                               | Архив:             [ ]                                           |
                                               |                                                                  |
                                               | Проектный объем часов: [1200]                                   |
                                               | Ставка часа проекта:  [3500]                                   |

```

## Поведение полей
- Если включен `Поддержка`, поле `Проектный объем часов` становится disabled.
- `Начало проекта` и `Конец проекта` дублируются из самого проекта Bitrix24.
- `Компания` хранится на стороне приложения как метаданные проекта.

## Какие поля штатные, а какие нет
- Из Bitrix проекта можно брать и обновлять:
  - `NAME`
  - `PROJECT_DATE_START`
  - `PROJECT_DATE_FINISH`
  - архивное состояние через `CLOSED`
- В приложении нужно хранить:
  - стадию
  - объем часов
  - ставку часа
  - поддержку
  - куратора
  - компанию
