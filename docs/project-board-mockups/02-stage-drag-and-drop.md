# Mockup 02: Перенос карточки между стадиями

## Цель экрана
Показать, как работает ручной перенос проекта между управляемыми стадиями.

## Wireframe
```text
+=======================================================================================================+
| Перемещение проекта между стадиями                                                                   |
+=======================================================================================================+
| В работе                                  | Успех                                                    |
|-------------------------------------------|----------------------------------------------------------|
|                                           |                                                          |
|  [ ACME внедрение ]                       |                                                          |
|  1200ч | 3500р | Иванов                   |                                                          |
|  01.04 - 30.09                            |                                                          |
|  Компания: ACME LLC                       |                                                          |
|  Последнее списание: 2д                   |                                                          |
|                                           |                                                          |
|             >>> пользователь тащит >>>    |   [ Drop zone ]                                          |
|                                           |                                                          |
+=======================================================================================================+
| Подтверждение перевода проекта                                                                      |
| Проект: ACME внедрение                                                                              |
| Новая стадия: Успех                                                                                 |
| Комментарий перехода: [ optional ]                                                                  |
| [Отмена] [Перевести]                                                                                |
+=======================================================================================================+
```

## Правила drag-and-drop
- Разрешен ручной перенос только для стадий:
  - `Новый`
  - `В просчете`
  - `В работе`
  - `Успех`
  - `Провал`
- Перенос в стадии:
  - `Нет списаний 1 месяц`
  - `Нет списаний 3 месяца`
  не выполняется вручную, только автоматически.

## Продуктовые решения
- После drop лучше показывать подтверждение, а не менять стадию мгновенно.
- Для `Успех` и `Провал` можно позже добавить обязательный комментарий перехода.

## Что оценивать
- Нужен ли модальный шаг подтверждения.
- Достаточно ли ограничить автостадии от ручного переноса.
