# Mockup 06: Автоматические стадии по отсутствию списаний

## Цель экрана
Показать механику, которая раз в день автоматически переводит проекты в специальные стадии.

## Wireframe
```text
+===============================================================================================================+
| Системная проверка проектов (ежедневно)                                                                     |
+===============================================================================================================+
| Проект             | Последнее списание | Текущая стадия | Результат проверки                                |
|--------------------|--------------------|----------------|---------------------------------------------------|
| Delta CRM          | 34 дня назад       | В работе       | -> Нет списаний 1 месяц                           |
| Legacy portal      | 98 дней назад      | В работе       | -> Нет списаний 3 месяца                          |
| ACME внедрение     | 2 дня назад        | В работе       | без изменений                                     |
| Omega migration    | 40 дней назад      | Нет списаний 1 месяц | без изменений                                 |
+===============================================================================================================+
| Правила                                                                                                       |
| - 30+ дней без списаний -> "Нет списаний 1 месяц"                                                            |
| - 90+ дней без списаний -> "Нет списаний 3 месяца"                                                           |
| - появилось новое списание после автостадии -> вернуть в "В работе"                                          |
+===============================================================================================================+
```

## Продуктовые решения
- Автостадии не редактируются вручную drag-and-drop.
- На карточке проекта нужен бейдж `Автостатус`.
- Желательно логировать причину системного перехода.

## Что оценивать
- Достаточно ли ежедневной проверки.
- Нужно ли уведомление куратору при автоматическом переводе.
