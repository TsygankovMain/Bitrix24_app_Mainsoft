# Мокапы: Project Board / Gantt для основного приложения

## Зачем этот набор
Этот набор нужен для оценки объема реализации перед разработкой функционала управления проектами внутри основного приложения.

## Что входит
0. `project-board-prototype.html` — интерактивный HTML-мокап в стиле текущего приложения
1. `01-board-overview.md` — главная доска проектов
2. `02-stage-drag-and-drop.md` — перенос карточек между стадиями
3. `03-project-card-states.md` — состав и состояния карточки проекта
4. `04-project-drawer-fields.md` — боковая панель редактирования проекта
5. `05-archive-behavior.md` — архив проектов
6. `06-auto-no-writeoff-transitions.md` — автоматические стадии по отсутствию списаний
7. `07-timeline-view.md` — отдельный timeline-вид (если нужен настоящий гант)

## Связанные документы реализации
- `../internal/project-board-implementation-plan.md` — этапы, состав MVP, оценка
- `../internal/project-board-technical-spec.md` — техническая спецификация для разработки

## Как смотреть
- Сначала открыть `project-board-prototype.html` и пройти сценарии руками.
- Сначала оценить, достаточно ли `Project Board` без timeline.
- Потом решить, нужен ли в MVP drag-and-drop.
- Отдельно принять решение, хотим ли мы `Timeline` в первой версии или оставляем на вторую итерацию.

## Что важно помнить
- Основное место размещения: standalone интерфейс приложения.
- Стадии фиксированные:
  - `Новый`
  - `В просчете`
  - `В работе`
  - `Нет списаний 1 месяц`
  - `Нет списаний 3 месяца`
  - `Успех`
  - `Провал`
- Архив не является стадией. Это отдельный флаг проекта.
- Автостадии по отсутствию списаний должны выставляться backend-проверкой раз в день.
