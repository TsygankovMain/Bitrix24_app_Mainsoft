# Mockup 01: Главная доска проектов

## Цель экрана
Главный экран для руководителя, где видно все активные проекты, их стадию, ключевые параметры и последние сигналы по активности.

## Что видно на карточке сразу
- Название проекта
- Проектный объем часов или признак `support`
- Ставка часа проекта
- Куратор
- Даты проекта
- Компания
- Давность последнего списания

## Продуктовые решения
- `Архив` вынесен из доски отдельной кнопкой, чтобы активные стадии не смешивались с архивными проектами.
- `Timeline` переключается с этой же страницы, не как отдельный модуль.
- В доске оставляем только ключевую управленческую информацию. Подробности уходят в drawer.
