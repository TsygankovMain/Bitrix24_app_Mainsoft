# Mockup 03: Состав и состояния карточки проекта

## Цель экрана
Зафиксировать, что должно быть прямо на карточке и как выглядят разные проектные состояния.

## Wireframe
```text
Обычный проект
+------------------------------------------------------+
| ACME внедрение                                       |
| 1200ч | 3500р/ч | Куратор: Иванов                    |
| 01.04.2026 - 30.09.2026                              |
| Компания: ACME LLC                                   |
| Последнее списание: 2 дня назад                      |
| [Открыть]                                            |
+------------------------------------------------------+

Проект поддержки
+------------------------------------------------------+
| Gamma support                                        |

| [Открыть]                                            |
+------------------------------------------------------+

Автостадия "нет списаний 1 месяц"
+------------------------------------------------------+

+------------------------------------------------------+
```

## Обязательные поля карточки
- Название проекта
- Проектный объем часов или маркер `support`
- Ставка часа проекта
- Куратор проекта
- Начало и конец проекта
- Компания
- Последнее списание

## Продуктовые решения
- Если включен `support`, поле проектного объема часов на карточке заменяется на бейдж `support`.
- Архивный проект не должен попадать в активную доску и стандартные отчеты.

## Что оценивать
- Хватает ли информации на карточке без перегруза.
- Нужны ли дополнительные индикаторы, например суммарные списанные часы.
