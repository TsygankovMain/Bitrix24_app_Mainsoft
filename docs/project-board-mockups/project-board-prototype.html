Управление проектами и стадиями

Живой мокап в визуальном стиле текущего приложения. Можно переключать режимы `Доска / Timeline / Архив`, перетаскивать карточки между ручными стадиями, открывать drawer проекта, включать `Поддержка`, архивировать проект и запускать ежедневную автопроверку стадий `Нет списаний`.
