# Mockup 05: Архив проектов

## Цель экрана
Показать, как отделяется архив от активной работы и как это влияет на отчеты.

## Wireframe
```text
+=======================================================================================================+
| Архив проектов                                                                                        |
| [Назад к доске]   Поиск: [ Legacy ... ]   Фильтр: [Компания v] [Куратор v]                          |
+=======================================================================================================+
| Legacy portal                    | Куратор: Волков     | Архивирован: 02.04.2026 | Компания: Legacy |
| Причина: проект завершен         | Последнее списание: 28.03.2026                                    |
| [Открыть] [Разархивировать]                                                                      |
|-------------------------------------------------------------------------------------------------------|
| Sigma pilot                      | Куратор: Орлов      | Архивирован: 15.03.2026 | Компания: Sigma  |
| Причина: провал                  | Последнее списание: 20.02.2026                                    |
| [Открыть] [Разархивировать]                                                                      |
+=======================================================================================================+
| Важно: архивные проекты не участвуют в отчетах и их метки времени не попадают в аналитические срезы |
+=======================================================================================================+
```

## Продуктовые решения
- Архив вынесен в отдельный экран/режим, а не как еще одна стадия.
- Разархивация должна возвращать проект в последнюю ручную стадию или в `В работе`.

## Поведение отчетов
- Архивный проект исключается из:
  - отчетов по сотрудникам
  - отчетов по проектам
  - отчетов по проектам/задачам
  - дневных отчетов
- Старые метки не удаляются, а просто фильтруются по `project_id`.

## Что оценивать
- Достаточно ли отдельного архивного списка.
- Нужен ли обязательный reason при архивировании.
