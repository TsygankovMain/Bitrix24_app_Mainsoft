# Mockup 07: Timeline-вид (если нужен настоящий гант)

## Цель экрана
Показать альтернативный вид, если все же нужен не только канбан, но и timeline по датам проектов.

## Wireframe
```text
+=====================================================================================================================+
| Проекты / Timeline                                                                                                  |
| Вид: [Доска] [Timeline]      Масштаб: [Месяц v]       Период: Апр 2026 - Окт 2026                                  |
+=====================================================================================================================+
| Проект                    | Апр              Май              Июн              Июл              Авг              Сен |
|---------------------------|-----------------------------------------------------------------------------------------|
| ACME внедрение            | [========== timeline bar ================================]                                  |
| Beta аудит                | [====]                                                                                     |
| Gamma support             | [============================= support ongoing ===============================]            |
| Delta CRM                 |      [==================]                                                                   |
| Legacy portal             | [archived]                                                                                 |
+=====================================================================================================================+
| Легенда                                                                                                             |
| - цвет полосы = стадия проекта                                                                                      |
| - архивные проекты по умолчанию скрыты                                                                              |
| - support-проекты показываются как длительные полосы без проектного объема часов                                    |
+=====================================================================================================================+
```

## Когда этот экран нужен
- Если руководителю важны сроки проектов и визуальное пересечение проектов по датам.
- Если доски по стадиям недостаточно для планирования загрузки.

## Когда этот экран можно отложить
- Если в первой версии основной сценарий — смена стадии и контроль отсутствия списаний.
- Если даты проектов часто неактуальны и timeline будет вводить в заблуждение.

## Что оценивать
- Нужен ли timeline уже в MVP.
- Достаточно ли read-only timeline без редактирования дат перетаскиванием.
