# Релизы «Учёт трудозатрат»

Заметные изменения **для пользователей**, человеческим языком. Технические детали — в [CHANGELOG.md](./CHANGELOG.md).

---

## Май 2026

### ⏳ Видно, что идёт обработка — Бобёр везде
- Теперь при **любой** долгой операции (формирование отчёта, выгрузка Excel, синхронизация, простановка ИНН) показывается прогресс с Бобром-Учётчиком 🦫. Понятно, что процесс идёт, а не завис.

### 📑 Единый красивый Excel во всех отчётах
- Теперь **все** отчёты выгружаются в Excel в едином структурном виде (как «Учет по проектам/задачам»): объединённая шапка с периодом, аккуратное форматирование, числа как числа, итоги, закреплённая шапка. Никаких плоских «простыней» — файлы готовы к отправке клиентам.
- Иерархические отчёты (по сотрудникам, по проектам) сохраняют и детальные строки; ежедневная нагрузка — матрицей сотрудник×день с итогами; сводные отчёты — аккуратными таблицами с процентами и деньгами.

### 🦫 Дозаполнение ИНН — удобнее, с заменой и Бобром-Учётчиком
- В **Настройках → «Незаполненные проекты»** теперь видно, у каких проектов не хватает данных для ИНН (компания, юр.лицо, ИНН в реквизитах) — с переходом к проекту для исправления.
- В дозаполнении ИНН проекты можно **сворачивать**; по кнопке **«Заполнить / Изменить ИНН»** открывается окно, где задаёшь ИНН на весь проект сразу и при необходимости **заменяешь** уже проставленный (когда сменилось юр.лицо).
- Долгие операции (простановка ИНН, синхронизация, выгрузка) показывают **прогресс с Бобром-Учётчиком** 🦫.
- Убраны лишние/дублирующие кнопки на вкладке дозаполнения.

### 📊 Отчёт «Учет по проектам/задачам» — новый вид и удобная выгрузка
- Отчёт приведён к единому стилю с остальными: сверху — наглядные карточки с итогами (**всего часов**, **учтено**, **не учтено**, **% учтённости**).
- Таблица иерархии (проект → задача → сотрудник → метки) стала аккуратнее: уровни различаются цветом и отступом, раскрываются по клику.
- **Выгрузка в Excel теперь сохраняет структуру.** Раньше в файл уходила плоская «простыня» — теперь это структурированный лист: проекты и задачи с группировкой и сворачиванием, объединённые заголовки, итоги. Такой файл не стыдно отправить клиенту.

### 🧾 Дозаполнение ИНН для выгрузки в 1С
- В разделе **«Сырые данные»** появилась вкладка **«Дозаполнение ИНН»**.
- За выбранный период приложение находит списания времени, у которых **не заполнен ИНН**, и подставляет его из проекта: ИНН клиента (из компании проекта) и ваш ИНН (из вашего юр.лица).
- Заполнить можно **массово** — одной кнопкой по всему проекту или по всем найденным, либо **вручную** для исключений (где в проекте нет данных).
- При **синхронизации** ИНН теперь автоматически проставляется новым карточкам списания (там, где он определяется из проекта).
- Итог: выгрузка «Сырые данные» с полями ИНН уходит в 1С уже заполненной.
