# Смоук-чек-лист миграции на B24 UI Kit

> Прогоняется **в конце каждого спринта** (S1–S5). Любой FAIL, который не чинится быстро → **откат спринта** (`git revert`) и разбор. Эталон сравнения — «зелёный» базлайн S0.

## Правила окружения (на всё время миграции)

- **Версия kit зафиксирована lock-файлом** (`frontend/pnpm-lock.yaml`): `@bitrix24/b24ui-nuxt` **2.5.3**, `@bitrix24/b24icons-vue` **2.0.7**, `@bitrix24/b24jssdk-nuxt` **0.5.1**.
- **НЕ запускать** `pnpm update`, **не пересобирать** lock-файл, **не менять** диапазоны в `package.json` — иначе kit может уехать на новый минор посреди миграции. Установка только `pnpm install --frozen-lockfile`.
- Деплой — как обычно (фронт/бэк), миграций БД миграция UI не добавляет.

## ⚠️ УТП — «Учёт по проектам/задачам» (особый контроль, S4)

- [ ] Иерархия строится: проект → задача → подзадача → сотрудник → метка.
- [ ] **Раскрытие/сворачивание** уровней работает (клик по строке).
- [ ] **Кликабельные метки** работают (переход к элементу).
- [ ] Уровни различаются цветом/отступом; KPI-карточки (всего/учтено/не учтено/%) верны.
- [ ] **«Скачать Excel» → открыть файл: иерархия/группировка/итоги сохранены** (структура не изменилась).
- [ ] Сверка со скриншотом «до» — визуально нативный, но функционально идентичный.

## ⚠️ Embedded — отражение времени (особый контроль, S5)

- [ ] **ИНН проставляется**: в консоли лог `[Embedded][INN] Verify saved item` → `savedOurInn`/`savedClientInn` заполнены (при заполненном проекте).
