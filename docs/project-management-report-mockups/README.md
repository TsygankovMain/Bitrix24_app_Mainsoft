# Project Management Report Mockups

Файлы:
- `index.html` — обзор трех новых отчетов
- `01-budget-burn-forecast.html` — освоение проектного объема и прогноз выгорания
- `02-portfolio-risk-radar.html` — риск-радар портфеля проектов
- `03-curator-load-and-risk.html` — нагрузка и качество портфеля по кураторам
- `assets/report-mockups.css` — общий стиль в визуальном языке приложения
- `assets/report-mockups.js` — общие демоданные и расчеты

## Почему именно эти отчеты

1. `Освоение проектного объема`
Показывает, где проектный объем уже почти закончился, где перерасход, и когда объем закончится по текущему темпу списаний.

2. `Риск-радар портфеля`
Собирает в один управленческий экран бездействие по списаниям, давление дедлайнов и пробелы в проектных полях.

3. `Портфель кураторов`
Позволяет увидеть, у кого из кураторов концентрируется перегруз, риск и некачественно оформленные проекты.

## На каких данных это основано

Используются только уже существующие данные проекта и списаний:
- `project_hours_budget`
- `hourly_rate`
- `stage`
- `is_support`
- `curator_name`
- `project_start_date`
- `project_end_date`
- `company_name`
- `our_legal_entity_name`
- `last_writeoff_days`
- фактические часы по проекту

## Как оценивать mockups

Смотри не на красоту карточек, а на три вопроса:
1. помогает ли экран принять решение без дополнительной ручной аналитики;
2. видно ли, на какой проект или куратора надо идти в первую очередь;
3. понятно ли, какие данные надо срочно дозаполнить в проекте.
