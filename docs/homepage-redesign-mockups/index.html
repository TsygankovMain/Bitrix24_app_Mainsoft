Mockups / Главная страница

8 концепций нового стартового экрана

Текущая главная страница работает как каталог плиток. Эти концепции показывают, как превратить ее в рабочую точку входа: с приоритетами, сигналами, KPI и быстрыми маршрутами в ключевые сценарии приложения.

Текущий паттерн
Плитки
Хорошо для навигации, слабо для операционного управления.
Новая цель
Рабочий хаб
Показывать, что важно сейчас, а не просто список экранов.
Формат
HTML
Каждый концепт интерактивен и открывается отдельно.
Новый набор
06-08 Compact
Три облегченных концепта с меньшей плотностью информации.

Концепты

Открывай любой вариант и сравнивай не только визуал, но и продуктовую логику входа в приложение.

01

Command Center

KPI, сигналы, синхронизация, быстрые действия и ключевые алерты в одном экране.
02

Priorities First

Вход через список приоритетов и маршрутов действий, а не через каталог разделов.
03

Portfolio Home

Главный экран как центр управления проектным портфелем с board-preview.
04

Role-Based Cockpit

Разный стартовый экран для руководителя, delivery и PM без отдельной настройки модулей.
05

Workspace Launchpad

Персональный стартовый экран с избранным, наблюдаемыми проектами и быстрым поиском.
06

Focus Start

Три рабочих трека на старте: сформировать, проверить риски, открыть проект.
07

Day Queue

Очередь дня с вкладками «Сегодня / Риски / Дальше» вместо перегруженного дашборда.
08

Clear Operator

Двухпанельный минимализм: проект слева, действия и контекст справа.
