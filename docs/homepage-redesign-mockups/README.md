# Мокапы новой главной страницы

Папка содержит 8 HTML-концепций переосмысления стартового экрана приложения.

## Быстрый вход

Открой:

- `docs/homepage-redesign-mockups/index.html`

## Состав

1. `01-command-center.html`
2. `02-priorities-first.html`
3. `03-portfolio-home.html`
4. `04-role-cockpit.html`
5. `05-workspace-launchpad.html`
6. `06-focus-start.html`
7. `07-day-queue.html`
8. `08-clear-operator.html`

## Логика набора

1. Первый концепт ближе всего к рабочему управленческому дашборду.
2. Второй делает акцент на сценариях и приоритетах.
3. Третий ставит в центр проекты и сигналы по проектному портфелю.
4. Четвертый показывает роль-зависимый стартовый экран.
5. Пятый проверяет идею персонализированного рабочего пространства.
6. Шестой предлагает очень компактный вход через 3 рабочих трека.
7. Седьмой делает старт экраном очереди задач на день.
8. Восьмой сводит вход к двухпанельному операторскому режиму.

## Для быстрого сравнения перегруженности

Если цель именно разгрузить стартовую, начинай с:

1. `06-focus-start.html`
2. `07-day-queue.html`
3. `08-clear-operator.html`

## Что сравнивать

1. Скорость понимания: понятно ли сразу, что делать.
2. Управленческая ценность: видно ли, где проблемы и куда идти.
3. Нагрузка на экран: не превращается ли стартовая страница в перегруженный отчет.
4. Реалистичность внедрения: насколько концепт ложится на текущую архитектуру приложения.
