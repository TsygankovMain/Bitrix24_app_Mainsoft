# Установка и первичная настройка приложения «Учёт трудозатрат»

## Назначение документа

Этот документ нужен администратору или внедренцу, который впервые разворачивает приложение и хочет довести его до рабочего состояния без чтения кода.

## 1. Что понадобится заранее

Перед установкой подготовьте:

- портал Bitrix24 с правами администратора;
- опубликованный URL приложения;
- доступ к переменным окружения приложения;
- понимание, в каком смарт-процессе будут храниться записи времени.

Если вы запускаете проект локально, сначала поднимите окружение и проверьте, что приложение открывается по своему внешнему URL.

## 2. Регистрация приложения в Bitrix24

При ручной установке используйте:

- URL приложения: `https://ваш-домен/`
- URL установки: `https://ваш-домен/install`

После установки приложение должно открываться из раздела приложений Bitrix24.

## 3. Первый запуск после установки

После первого запуска откройте:

- `Настройки`
- затем `Настройка полей (Маппинг)`

Именно этот экран используется для первичной конфигурации приложения: смарт-процесса меток времени, смарт-процесса проектов (Project SPA) и маппинга полей.

## 4. Настройка смарт-процесса

На странице маппинга доступны три базовых сценария:

### Сценарий 1. Уже есть готовый смарт-процесс

1. Выберите нужный смарт-процесс в списке.
2. Нажмите `Подгрузить поля`.
3. Убедитесь, что список полей загрузился.
4. Выполните сопоставление полей приложения и полей Битрикс24.
5. Нажмите `Сохранить`.

### Сценарий 2. Смарт-процесса еще нет

1. Нажмите `Создать смарт-процесс`.
2. Дождитесь завершения операции: процесс создается вместе с обязательными полями и базовым маппингом.
3. Проверьте, что новый процесс выбран автоматически и маппинг заполнен.
4. При необходимости для отдельного поля используйте пункт `+ Создать поле «...»` прямо в выпадающем списке маппинга.
5. Нажмите `Сохранить`.

### Сценарий 3. Нужно обновить существующую конфигурацию

1. Откройте страницу маппинга.
2. Выберите текущий смарт-процесс.
3. Подгрузите поля.
4. Исправьте сопоставления или ставку часа.
5. При необходимости обновите маппинг полей `Смарт-процесса ПРОЕКТ`.
6. Нажмите `Сохранить`.

## 5. Какие поля должны быть сопоставлены

Для корректной работы приложения важны как минимум следующие поля:

| Поле приложения | Назначение |
|---|---|
| `id_zadachi` | ID задачи Bitrix24 |
| `sotrudnik` | сотрудник |
| `kolichestvo_chasov` | часы |
| `uchitivaem` | учитываемая или неучитываемая запись |
| `opisanie` | описание работы |
| `project_title` | название проекта |
| `project_id` | ID проекта |
| `project_item_id` | ID карточки проекта в Project SPA |
| `data` | дата отражения |
| `id_zadach_ierarhiya` | иерархия ID задач |
| `title_zadach_ierarhiya` | иерархия названий задач |
| `task_name` | название задачи |
| `our_inn` | ИНН нашей компании |
| `client_inn` | ИНН клиента |

Поля `project_item_id`, `our_inn` и `client_inn` обязательны для корректной проектной и финансовой аналитики. Служебные поля второго уровня можно добавлять по мере необходимости.

## 6. Ставка часа

На странице маппинга можно задать `Стоимость часа (по умолчанию)`.

Эта ставка:

- используется в расчете сумм внутри приложения;
- помогает интерпретировать учитываемые часы в денежном выражении;
- должна быть заполнена до начала активной работы, если вы используете финансовые показатели.

## 7. Проверка работы в задаче

После сохранения конфигурации проверьте основной пользовательский сценарий:

1. Откройте любую задачу в Bitrix24.
2. Перейдите во вкладку приложения.
3. Нажмите `Отразить`.
4. Заполните описание, часы и дату.
5. Сохраните запись.

Если все настроено правильно, запись появится в интерфейсе задачи и будет участвовать в отчетах.

## 8. Проверка отчетов

Откройте любой отчет из главного меню и выполните базовую проверку:

1. Выберите период.
2. При необходимости укажите сотрудников и проекты.
3. Нажмите `Сформировать`.
4. Убедитесь, что данные отображаются в интерфейсе.
5. При необходимости проверьте `Скачать Excel`.

Доступные основные отчеты:

- отчет по сотрудникам;
- отчет по проектам;
- ежедневная нагрузка;
- учет по проектам и задачам;
- потери выручки;
- дисциплина внесения времени;
- фокус и распыление.

## 9. Раздел «Сырые данные (БД)»

Этот раздел находится в настройках и нужен для администрирования.

Здесь можно:

- запускать ручную синхронизацию с Bitrix24;
- смотреть локально сохраненные записи;
- фильтровать локальный кэш по дате создания;
- выгружать данные в Excel напрямую из Bitrix24 с выбором полей.

Раздел особенно полезен при первичной диагностике, если отчетность выглядит неполной или неожиданной.

## 10. Что проверить после настройки

После завершения первичной настройки желательно проверить:

- запись времени создается в задаче;
- данные видны хотя бы в одном отчете;
- фильтры по сотрудникам и проектам открываются и позволяют выбрать значения;
- Excel выгружается;
- ставка часа отображается в задаче;
- раздел маппинга сохраняет изменения без ошибок.

## 11. Частые проблемы

### Отчет пустой

Проверьте:

- выбран ли корректный период;
- есть ли записи в смарт-процессе;
- сохранен ли маппинг;
- не исключены ли нужные сотрудники или проекты фильтрами.

### Не видны поля смарт-процесса

Обычно помогает:

- заново выбрать смарт-процесс;
- нажать `Подгрузить поля`;
- проверить права приложения в Bitrix24.

### Не создается поле из выпадающего списка маппинга

Проверьте:

- выбран ли смарт-процесс;
- достаточно ли прав у приложения на изменение полей CRM;
- нет ли уже поля с тем же кодом/назначением.

### Не работает вкладка в задаче

Проверьте, что приложение открывается внутри Bitrix24, а не по прямому URL встроенной страницы.

### Ошибка запуска через cloudpub-домен (`host is not allowed`)

Проверьте, что внешний домен добавлен в `frontend/nuxt.config.ts` в `vite.server.allowedHosts`, затем перезапустите локальную среду.

### Непонятно, откуда брать данные для Excel

Если нужен Excel по отчету, используйте кнопку `Скачать Excel` в самом отчете.
Если нужен Excel по исходным данным, используйте раздел `Сырые данные (БД)`.
