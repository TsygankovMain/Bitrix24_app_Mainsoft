# Установка и первичная настройка

Документ для администратора Bitrix24 после того, как production-версия приложения уже развернута на сервере.

## 1. Что нужно заранее

- production URL приложения;
- права администратора в Bitrix24;
- `CLIENT_ID` и `CLIENT_SECRET` приложения;
- понимание, где будут храниться:
  - записи времени;
  - карточки проектов.

## 2. Регистрация приложения в Bitrix24

Укажите:

- URL приложения: `https://ваш-домен/`
- URL установки: `https://ваш-домен/install`

После установки backend сам выполняет bind основных placement’ов.

## 3. Первый вход

После открытия приложения перейдите в:

- `Настройки`
- затем `Настройка полей (Маппинг)`

Здесь настраиваются:

- смарт-процесс меток времени;
- project SPA;
- маппинг полей;
- ставка часа.

## 4. Настройка смарт-процесса меток времени

### Если СП уже существует

1. Выберите нужный СП.
2. Нажмите `Подгрузить поля`.
3. Проверьте маппинг.
4. Нажмите `Сохранить`.

### Если СП еще нет

1. Нажмите `Создать смарт-процесс`.
2. Дождитесь создания СП и обязательных полей.
3. Проверьте, что базовый маппинг появился автоматически.
4. При необходимости используйте `+ Создать поле "..."` прямо из dropdown конкретного поля.
5. Нажмите `Сохранить`.

## 5. Обязательные поля меток времени

Минимальный рабочий набор:

| Поле приложения | Назначение |
|---|---|
| `id_zadachi` | ID задачи |
| `sotrudnik` | сотрудник |
| `kolichestvo_chasov` | часы |
| `uchitivaem` | учитываемая запись |
| `opisanie` | описание |
| `project_title` | название проекта |
| `project_id` | ID проекта |
| `project_item_id` | ID карточки проекта SPA |
| `data` | дата отражения |
| `task_name` | название задачи |
| `our_inn` | наш ИНН |
| `client_inn` | ИНН клиента |

Для проектной аналитики особенно важны:

- `project_item_id`
- `our_inn`
- `client_inn`

## 6. Проверка project SPA

В разделе настроек проверьте:

1. выбран ли project SPA;
2. загружаются ли поля project SPA;
3. заполнен ли маппинг полей проекта;
4. доступны ли стадии project SPA.

## 7. Проверка основного сценария

### В задаче

1. Откройте любую задачу.
2. Перейдите во вкладку приложения.
3. Создайте тестовую запись времени.
4. Проверьте сохранение.

### В отчетах

1. Откройте любой отчет.
2. Выберите период.
3. Нажмите `Сформировать`.
4. Проверьте отображение результата и Excel.

### В проектах

1. Откройте раздел проектов.
2. Проверьте загрузку карточек и метаданных.
3. Проверьте компании, кураторов и стадии.

## 8. Частые проблемы

### Вкладка в задаче не появилась

Проверьте:

- корректность URL приложения и URL установки;
- выполнен ли reinstall после смены домена;
- есть ли bind `TASK_VIEW_TAB`.

### Отчеты пустые

Проверьте:

- период;
- корректность маппинга;
- наличие данных в СП;
- синхронизацию локального кэша.

### Поля не загружаются

Проверьте:

- выбран ли нужный СП;
- есть ли права приложения на CRM и userfield config;
- сохранен ли `CLIENT_ID/CLIENT_SECRET`.
