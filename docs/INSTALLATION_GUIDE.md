## 1. Системные требования

| Компонент | Требование |
|-----------|-----------|
| Битрикс24 | Облачная версия, тариф «Профессиональный» и выше |
| Смарт-процессы | Должны быть доступны на вашем тарифе |
| Браузер | Chrome 90+, Firefox 88+, Safari 14+, Edge 90+ |
| Права | Администратор портала (для установки) |

## 2. Установка приложения

### Из Маркетплейса
1. Перейдите в **Маркетплейс Битрикс24** → найдите **«TimeTracker Pro»**
2. Нажмите **«Установить»**
3. Подтвердите запрашиваемые права доступа
4. Дождитесь завершения установки (отобразится анимация прогресса)

### Ручная установка (для разработчиков)
1. В разделе **Приложения → Разработчикам → Добавить приложение → Серверное** укажите:
   - **URL приложения**: `https://ваш-домен.com/`
   - **URL установки**: `https://ваш-домен.com/install`
   - **Путь для бэкенда**: `https://ваш-домен.com/api/`
2. В разделе **Вкладки** добавьте placement `TASK_VIEW_TAB` с handler: `https://ваш-домен.com/embedded`

## 3. Первичная настройка

После установки приложение доступно через **Приложения → TimeTracker Pro**.

При первом запуске вы увидите главную страницу с плитками отчётов. Перед использованием необходимо:
1. Создать Смарт-процесс (если его нет)
2. Настроить маппинг полей

---

## 4. Настройка Смарт-процесса и Полей

Теперь приложение умеет создавать Смарт-процесс и поля автоматически.

1. Перейдите в **Настройки → Маппинг**.
2. Если у вас нет подходящего Смарт-процесса:
   - Нажмите кнопку **«Создать Смарт-процесс»**
   - Приложение создаст новый процесс «Метки времени (TimeTracker)»
   - Страница перезагрузится, новый процесс появится в списке
3. Выберите созданный (или существующий) Смарт-процесс из списка.
4. Нажмите кнопку **«Создать все поля»**:
   - Приложение автоматически создаст необходимые поля в Битрикс24
   - Будут созданы поля: `ID задачи`, `Сотрудник`, `Часы`, `Иерархия`, `Названия`, `ИНН` и другие
   - **Важно:** Поля иерархии создаются как множественные
5. После создания полей нажмите **«Сохранить»**
   - Конфигурация запишется в настройки приложения
   - Маппинг заполнится автоматически

## 5. Проверка маппинга

Убедитесь, что все поля сопоставлены корректно (обычно это происходит автоматически после нажатия «Создать все поля»):

| Поле приложения | Описание |
|----------------|----------|
| `id_zadachi` | ID задачи |
| `sotrudnik` | Сотрудник |
| `kolichestvo_chasov` | Часы |
| `uchitivaem` | Учитываем? |
| `opisanie` | Описание |
| `project_title` | Название проекта |
| `project_id` | ID проекта |
| `data` | Дата |
| `id_zadach_ierarhiya` | Иерархия ID (множественное) |
| `title_zadach_ierarhiya` | Иерархия Названий (множественное) |
| `task_name` | Название задачи |
| `our_inn` | Наш ИНН |
| `client_inn` | ИНН клиента |

## 6. Настройка вкладки в задаче

Для встраивания виджета учёта часов в карточку задачи:

1. При установке через маркетплейс вкладка настраивается автоматически
2. При ручной установке: добавьте **placement** типа `TASK_VIEW_TAB` с handler `/embedded`

После настройки в каждой задаче появится вкладка **«Учёт часов»** с интерфейсом для фиксации времени.

---

## 7. Проверка работоспособности

### Тест учёта часов
1. Откройте любую задачу → вкладка **«Учёт часов»**
2. Нажмите **«Отразить»** → введите описание, часы, выберите сотрудника
3. Нажмите **«Сохранить»** → запись должна появиться в списке

### Тест отчётов
1. На главной странице приложения нажмите **«Обновить данные»** в любом отчёте
2. Дождитесь синхронизации (загрузка данных из Битрикс24 в локальную БД)
3. Примените фильтры по датам → должны отобразиться введённые метки

### Тест экспорта
1. В отчёте нажмите **«Excel»** → должен скачаться файл `.xlsx`

## Частые вопросы

**Q: Отчёты пустые, хотя часы внесены.**
A: Нажмите кнопку «Обновить» (синхронизация) в отчёте. Данные загружаются из Б24 в локальную БД.

**Q: Вкладка не появляется в задаче.**
A: Проверьте, что placement `TASK_VIEW_TAB` зарегистрирован в настройках приложения.

**Q: Ошибка «Не передан ID задачи».**
A: Виджет работает только внутри карточки задачи Б24. Не открывайте URL `/embedded` напрямую.
