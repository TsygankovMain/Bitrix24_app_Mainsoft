Не запланированные в текущие спринты идеи и улучшения. По мере проработки переходят в спек (`docs/superpowers/specs/`) и реализацию. Реализованное — переносится в [CHANGELOG.md](./CHANGELOG.md) / [RELEASES.md](./RELEASES.md).

## UX / Интерфейс

### Глобальный прогресс-бар для длительных операций
- Везде, где идут длительные запросы (синхронизация списаний/проектов, дозаполнение ИНН пачками, генерация отчётов и Excel-выгрузка), показывать **всплывающий прогресс-бар**.
- Сейчас прогресс частичный/текстовый (напр. в дозаполнении ИНН — «простановка X / Y»). Нужно единое, заметное визуальное решение.
- 💡 Рассмотреть **маскота/анимированного персонажа** (в духе миньона) как индикатор процесса — снизить ощущение ожидания, повысить вовлечённость. Подумать над характером/анимациями.
- Кандидат на переиспользуемый компонент (`components/common/ProgressOverlay.vue` + composable).

## Технологии / Дизайн-система

### Оценка перехода на Bitrix24 UI Kit (`@bitrix24/b24ui-nuxt`)
- Провести **аудит**: где уже используется B24 UI Kit (`B24Button`, `B24Card`, `ProseH2`…), а где самописная вёрстка (классы `ms-*`, кастомные таблицы отчётов, фильтры).
- Оценить **трудозатраты и выгоды** полного перехода: консистентность с Bitrix24, поддержка, тёмная тема, доступность.
- Решить стратегию: **полная миграция vs гибрид** (оставить кастомные таблицы там, где B24-компонентов не хватает).
- Результат — спек в `docs/superpowers/specs/` с поэтапным планом.
