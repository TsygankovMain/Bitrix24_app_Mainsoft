# Список неиспользуемых файлов

Следующие файлы и директории были идентифицированы как устаревшие или не используемые в текущей архитектуре приложения (Nuxt Frontend + Django Backend):

1.  **`index_test.html`**
    *   *Описание*: Устаревший прототип (Single File HTML), содержащий логику на React. Реальное приложение переписано на Vue 3 (Nuxt) и находится в директории `frontend/`.

2.  **`backend/`** (директория)
    *   *Описание*: В корне проекта находится папка `backend`, которая содержит только статический `Dockerfile` и пустую структуру. Реальный код бэкенда на Python находится в директории `backends/python/api`.

3.  **`Plan_app.md`**
    *   *Описание*: Старый файл планирования интерфейса. Текущая реализация интерфейса в `frontend/` уже ушла вперед от этого плана.

4.  **`instructions/`** (директория)
    *   *Описание*: Содержит старые промпты и инструкции по генерации кода, которые не нужны для работы самого приложения.
