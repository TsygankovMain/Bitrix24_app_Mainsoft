# Перенос копии портала на тестовый

Инструменты, которыми 5 сентября 2026 сделана копия рабочих данных
на портал nfr-mainsoft: смарт-процессы там уже были созданы приложением,
переносились компании, проекты и списания часов за август.

- `migrate.py` — три слоя переноса (`companies` → `projects` → `items`) и `check`
  для сверки количества записей и суммы часов. Идемпотентный: карты соответствия
  old→new лежат рядом в JSON, повторный запуск дозаливает недостающее.
- `setup_config.py` — маппинг смарт-процессов и полей в установленном приложении.
  Соответствие строится по суффиксу поля, а не по порядку.

Выгруженные данные (`august_*.json`, `map_*.json`) намеренно не в репозитории:
там ИНН, названия клиентов и часы. Рабочий каталог — `/srv/timesheet-demo/migration`.

Переменные окружения: `B24_MAINSOFT_WEBHOOK` (источник), `B24_WEBHOOK` (приёмник).

## Что учесть при повторе

Битрикс создаёт поле типа `double` с нулевой точностью, если её не передать явно,
и молча округляет часы: 0.5 превращается в 1. На nfr так округлилось 254 записи
из 796. В установщике это исправлено (`PRECISION: 2`), но на портале, где поля
создавались раньше, точность надо поправить руками через `userfieldconfig.update`.
