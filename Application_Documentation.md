# Документация продукта: «Учёт трудозатрат» для Bitrix24

> Версия документа: 2026-04
> Тип документа: продуктовое описание

## 1. Что это за продукт

«Учёт трудозатрат» — это встроенное приложение для Bitrix24, которое помогает:

- фиксировать рабочее время прямо в задаче;
- отделять учитываемые и неучитываемые часы;
- хранить записи в смарт-процессе CRM;
- получать управленческие и аналитические отчеты по работе команды.

Приложение ориентировано на команды, которым нужен не просто тайм-трекер, а прозрачная аналитика по сотрудникам, проектам и качеству учета времени.

## 2. Для кого приложение

| Роль | Польза |
|---|---|
| Сотрудник | быстро вносит время без перехода в сторонние системы |
| Руководитель проекта | видит загрузку команды и структуру трудозатрат |
| Руководитель отдела | анализирует эффективность, распределение ресурсов и дисциплину учета |
| Финансы | получает базу для контроля учитываемых и неучитываемых часов |
| Администратор | управляет маппингом, смарт-процессом и диагностикой |

## 3. Основные сценарии использования

### Сценарий 1. Учет времени в задаче

Пользователь открывает задачу в Bitrix24 и во встроенной вкладке приложения:

- добавляет запись времени;
- указывает описание, часы и дату;
- отмечает, должна ли запись учитываться в аналитике;
- при необходимости изменяет, разделяет или удаляет запись.

### Сценарий 2. Формирование отчетов

Руководитель открывает нужный отчет:

- выбирает период;
- задает фильтры по сотрудникам и проектам;
- при необходимости исключает отдельные значения через режим `кроме`;
- нажимает `Сформировать`;
- анализирует данные в интерфейсе или выгружает их в Excel.

### Сценарий 3. Настройка и поддержка

Администратор:

- выбирает или создает смарт-процесс;
- создает поля;
- задает ставку часа;
- сохраняет маппинг;
- использует сырые данные и отладку для диагностики.

## 4. Основные модули продукта

### 4.1. Вкладка в задаче

Это главный операционный экран для сотрудников.

Возможности:

- работа по дереву задач;
- добавление записи времени по нужной задаче;
- отображение накопительных итогов;
- расчет суммы по ставке часа;
- разделение записи на части;
- удаление и редактирование записи.

### 4.2. Отчеты

В приложении доступны 7 основных отчетов:

1. Отчет по сотрудникам
2. Отчет по проектам
3. Ежедневная нагрузка
4. Учет по проектам и задачам
5. Потери выручки
6. Дисциплина внесения времени
7. Фокус и распыление

Они покрывают три уровня аналитики:

- базовая управленческая отчетность по сотрудникам и проектам;
- оперативный контроль загрузки;
- аналитика качества учета времени и потерь.

### 4.3. Сырые данные

Служебный раздел для продвинутых пользователей и администраторов.

Позволяет:

- запускать синхронизацию;
- смотреть локальный кэш записей;
- фильтровать данные по дате создания;
- делать динамическую Excel-выгрузку по выбранным полям.

### 4.4. Настройки

В настройках доступны:

- экран маппинга;
- настройка кликабельных меток в отчетах;
- переход в сырые данные;
- отладочная панель.

## 5. Как устроены данные

С точки зрения пользователя логика продукта выглядит так:

1. пользователь вносит время в задаче;
2. запись попадает в смарт-процесс Bitrix24;
3. backend приложения синхронизирует эти записи в локальную базу;
4. отчеты строятся по локальному кэшу и отдают агрегированную аналитику.

Это разделение нужно для стабильной отчетности, фильтров, Excel-выгрузок и последующей оптимизации производительности.

## 6. Что нового в текущей версии продукта

Актуальный набор возможностей включает:

- 3 новых аналитических отчета: потери выручки, дисциплина внесения времени, фокус и распыление;
- ручное формирование отчетов по кнопке `Сформировать`;
- отдельную загрузку сотрудников и проектов для фильтров;
- режим `кроме` в фильтрах сотрудников и проектов;
- улучшенную страницу сырых данных с фильтрацией и динамической Excel-выгрузкой;
- встроенный пользовательский guide внутри приложения.

## 7. Ценность для бизнеса

Продукт закрывает сразу несколько задач:

- снижает потери времени на ручной учет;
- повышает прозрачность по проектам и сотрудникам;
- помогает находить неучтенные часы;
- позволяет отслеживать дисциплину ведения учета;
- дает материал для операционных и финансовых решений.

## 8. Ограничения и важные замечания

- без корректного маппинга приложение не сможет полноценно работать;
- отчеты зависят от структуры и качества данных в смарт-процессе;
- часть административных функций ориентирована на опытного пользователя;
- для финансовой интерпретации данных рекомендуется настроить ставку часа.
