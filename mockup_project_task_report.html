📋 Описание структуры отчета

Иерархия группировки:

Если задача БЕЗ подзадач:
📁 Проект → 📋 Задача → 👤 Сотрудник → 🕐 Метки времени

Если задача С подзадачами:
📁 Проект → 📋 Задача → 🔹 Подзадача → 👤 Сотрудник подзадачи → 🕐 Метки времени

Демоданные в мокапе:

  • Проект 1 "ООО РосТехСтрой" — содержит 2 задачи: одну без подзадач (3 сотрудника), одну с двумя подзадачами
  • Проект 2 "ИП Козлов" — содержит 1 задачу без подзадач с 1 сотрудником
  • Демонстрируются оба варианта: прямые записи в задаче и через подзадачи
  • Показаны учтённые (зелёные) и неучтённые (красные) часы

Столбцы:

  • Всего — общее количество часов на уровне
  • Учтено — часы с флагом "Учитывать" = Да (зелёный цвет)
  • Не учтено — часы с флагом "Учитывать" = Нет (красный цвет)
